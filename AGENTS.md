# Project Design Rules & User Preferences

## UI Color & Styling Preference
- **Single Cohesive Color Scheme**: Do NOT use multi-colored, rainbow, or varied accent colors (e.g. mixing cyan, green, amber, pink, and purple in lists or tool cards).
- **Brand Consistency**: Always use the project's single primary brand color (`--violet` / `--violet-light`, `#7c3aed` / `#a78bfa` / `#6d28d9`) across badges, icon containers, arrows, charts, and interactive tool cards.
- **Clean & Unified**: Keep cards and UI elements monochromatic with the brand theme, using opacity/alpha variants (e.g., `rgba(124, 58, 237, 0.12)`) rather than introducing different color families.
